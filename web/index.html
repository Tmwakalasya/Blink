How it works

  1. 01

    Start

    Blink asks Compute Engine for a VM of the size you picked, with an SSH key generated for that VM only.

  2. 02

    Connect

    Once the VM boots, Blink checks its SSH host key against the one Google publishes for it, then opens the terminal here.

  3. 03

    Use

    You log in as blink, with sudo. The session carries on if you reload the page.

  4. 04

    Delete

    Compute Engine deletes the VM when its lifetime ends, whether or not Blink is still running. Delete VM removes it sooner.
