How Blink works
  1. 01

    Create

    Compute Engine starts a VM of the size you picked, with an SSH key made for that VM alone.

  2. 02

    Connect

    Blink checks the VM's host key against the one Google publishes, then opens it here.

  3. 03

    Work

    Development and Compute include VS Code; every workspace has a terminal. You're blink, with sudo.

  4. 04

    Take your work with you

    Push your code to a repository or download files from VS Code before time runs out. The VM and its files are then deleted, even if Blink is offline.

    Starting VS Code on the VM

    Take your work with you.

    Blink deletes the VM and everything on it when your session ends.

    1. Using Git? Commit your changes and push them to your remote repository. A local commit alone will not survive deletion.
    2. Using VS Code? Right-click a file in the Explorer and choose Download. Save what you need to your computer.
    3. Using the terminal? Transfer files to your own storage before the timer runs out.

    End this session?

    The workspace and all its files will be permanently deleted. Make sure you've pushed or downloaded your work.
