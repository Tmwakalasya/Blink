How it works

  1. 01

    Start

    Blink asks Compute Engine for the VM described above, with an SSH key generated for that VM only.

  2. 02

    Connect

    Once the VM boots, Blink checks its SSH host key against the one Google publishes for it, then opens the terminal here.

  3. 03

    Use

    You log in as blink, with sudo. Copy SSH command lets you connect from your own terminal as well.

  4. 04

    Delete

    Compute Engine deletes the VM after 30 min, whether or not Blink is still running. Delete VM removes it sooner.
