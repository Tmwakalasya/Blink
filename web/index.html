How Blink works
  1. 01

    Create

    Compute Engine starts a VM of the size you picked, with an SSH key made for that VM alone.

  2. 02

    Connect

    Blink checks the VM's host key against the one Google publishes, then opens it here.

  3. 03

    Work

    Medium and Large open VS Code; every size has a terminal. You're blink, with sudo.

  4. 04

    Expire

    Compute Engine deletes the VM when its lifetime ends, even if Blink is offline.
